# data/This folder holds the raw input data for the analysis. Its contents areexcluded from version control (see `.gitignore`) to protect participantconfidentiality.\---## Expected filesPlace the two SPSS data files in `data/raw/` before running `LCA\\\\\\\_Analyses.R`:|File|Description||-|-||`Part1\\\\\\\_19082024\\\\\\\_clean\\\\\\\_JM\\\\\\\_version2.sav`|DA sample — Dutch adults (cross-sectional survey)||`Part2\\\\\\\_19082024\\\\\\\_clean\\\\\\\_JM\\\\\\\_version2.sav`|L sample — Dutch adults (cross-sectional survey)|The file paths are set at the top of `LCA\\\\\\\_Analyses.R` (Section 1) and can bechanged there if your files have different names or locations.\---## Data accessThe raw data are not publicly available. They contain sensitive health anddemographic information collected under ethics approval.
